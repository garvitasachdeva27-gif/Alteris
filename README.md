# Alteris

**Where Great Prompts Evolve.**

Alteris is an AI Prompt Engineering Platform — a workspace for creating, testing,
versioning, comparing, and analyzing AI prompts, built as a capstone project.

**Live demo:** _add your deployed frontend URL here after completing deployment_
*(Note: if hosted on Render's free tier, the backend may take 30–50s to wake up on first load.)*

## Features

- **Authentication** — JWT-based signup/login with hashed passwords
- **Prompt Library** — full CRUD for saved prompts, organized by category
- **Prompt Testing** — execute any prompt against Groq's LLM API with live token/latency metrics
- **Execution History** — every test run is logged and browsable per prompt
- **Version Control** — snapshot prompt states over time, with revert support
- **A/B Testing** — compare two prompt versions against identical input, run concurrently
- **Analytics** — per-prompt performance stats and a global cost/usage dashboard with charts

## Setup Guide

### 1. Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in real values:

```
GROQ_API_KEY=your_groq_api_key
JWT_SECRET_KEY=a_long_random_string
```

Generate a strong random secret with:
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Run the server:
```bash
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`, with interactive docs at
`http://127.0.0.1:8000/docs`.

### 2. Frontend

Open `frontend/index.html` directly in a browser, or serve it with any static
file server (e.g. the VS Code "Live Server" extension). Confirm `API_BASE` at
the top of `script.js` points to your running backend.

### 3. Running Tests

```bash
cd backend
pytest test_alteris.py -v
```

19 automated tests cover authentication, prompt CRUD, ownership isolation
(the security-critical check that users can't access each other's data),
version control, and input validation. See `TEST_CASES.md` for the full list.

## API Documentation

Full interactive API documentation (auto-generated by FastAPI) is available
at `/docs` on any running instance of the backend. See `API_DOCUMENTATION.md`
in this repository for a static, human-readable reference.

## Deployment

The project is designed to deploy as two separate Render services:

- **Backend** — a Render Web Service, root directory `backend`, start command
  `uvicorn main:app --host 0.0.0.0 --port $PORT`, with `GROQ_API_KEY`,
  `JWT_SECRET_KEY`, and `FRONTEND_URL` set as environment variables.
- **Frontend** — a Render Static Site, root directory `frontend`, no build
  command required.

After both are live, update `API_BASE` in `frontend/script.js` to the deployed
backend URL, and set `FRONTEND_URL` on the backend to the deployed frontend URL
(this locks down CORS to only accept requests from your real frontend).
